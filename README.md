# Customer Behavior Analysis (SQL)

## Overview

Analyzed customer purchasing behavior using SQL on a large-scale e-commerce dataset.

## Key Insights

* High customer retention (reorders exceed first-time purchases)
* Identified top-selling products (e.g., bananas, organic items)
* Customers segmented into High, Medium, and Low value groups
* High-value users represent a smaller but highly engaged segment

## Techniques Used

* JOIN operations
* Aggregations (COUNT, GROUP BY)
* CASE WHEN for segmentation
* Subqueries for distribution analysis

## Tools

* PostgreSQL
